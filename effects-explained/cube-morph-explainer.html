Dual-Stream 16-Bit Vertex & Normal Morphing fn_3c124 @ 0x3c2b1

Nation0 represents both the Cube and the Torus with an identical topological vertex mesh (corresponding coordinate and lookup streams). In each frame, the engine interpolates both the 3D coordinates and the surface normal vectors:

1. Fixed-Point Linear Blend 0x3c2c5
P_{morph} = ⌊ ( P_{cube} · t ) / 512 ⌋ + ⌊ ( P_{torus} · (511 - t) ) / 512 ⌋ N_{morph} = ⌊ ( N_{cube} · t ) / 512 ⌋ + ⌊ ( N_{torus} · (511 - t) ) / 512 ⌋
The blend parameter t ∈ [0, 511] is stored at DS:[0x3bdc1]. The original complement is 0x1ff − t; each signed product is shifted separately by 9. The preview reverses the UI weight to keep 0 = torus and 511 = cube; the original first stream is the torus. It preserves the 511 complement and each separate signed shift.
2. Matched Vertex Topology
Original stream A (torus): 0x33392 + offset ↔ Stream B (cube): 0x34e92 + offset Offsets run from −0x900 through −2 (1,152 signed words) Lookup stream bases come from pointers at DS:[0x3611a] and DS:[0x360e2]
Because the two meshes share identical facet index lists, no polygon stitching or dynamic vertex allocation is needed at runtime.

Sphere Environment Mapping (Chrome Reflection) fn_37cf7 @ 0x37cf7

Environment mapping creates the illusion of a polished chrome surface reflecting a surrounding room. Rather than tracing rays, Nation0 derives texture (U, V) directly from rotated vertex normal vectors:

1. Camera-Space Normal Transformation 0x37d20
N_{x,cam} = R_{00} · N_x + R_{01} · N_y + R_{02} · N_z N_{y,cam} = R_{10} · N_x + R_{11} · N_y + R_{12} · N_z
Transforms the surface normal into camera coordinates using the same 3 × 3 matrix that rotates the 3D model.
2. Direct Reflection UV Projection with 0x8080 Bias 0x37d40
U = packed transformed lookup low byte + center bias // 0x8080 center bias V = packed transformed lookup high byte + center bias // 256×256 texture map
The original uses patched fixed-point matrix coefficients, byte packing, and a word addition of 0x8080; the preview uses scaled floating-point normals. The (X, Y) components of the camera-space normal directly index the pre-rendered metallic sphere map.

The x86 Scanline Affine Texture Rasterizer Loop fn_332b6 @ 0x332b6

For each visible triangle, fn_332b6 divides the shape into top and bottom trapezoids, steps sub-pixel edge gradients (dX/dY, dU/dY, dV/dY), and executes an ultra-tight inner span loop reading from segment FS:[0]: 

Conceptual affine span (pseudocode, not verbatim assembly):
for each covered scanline:
    find left/right X, U and V from triangle edges
    for each covered pixel:
        write texture[(V_integer & 255) * 256 + (U_integer & 255)]
        advance interpolated U and V
1. FS Segment Selector Trick

By mapping the 64KB (256 × 256) texture to segment FS, the high 8 bits of BX index the row V and the low 8 bits index column U with zero shift or multiplication instructions!

2. Aspect Ratio Scaling (470 / 512)

In fn_37dac, projected Y coordinates are multiplied by 0x1d6 (470) and shifted right by 9 (512), correcting for the non-square 1.2:1 pixel aspect ratio of VGA Mode 13h (320 × 200).

3. Backface Determinant

A signed determinant selects the accepted winding (the original accepts a nonnegative result): (X₁ - X₀)(Y₂ - Y₀) - (Y₁ - Y₀)(X₂ - X₀) < 0, rejecting facets with the discarded winding; the proportion varies with geometry and pose.
